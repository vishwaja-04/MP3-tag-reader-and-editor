# MP3 Tag Reader in C

📌 Description

The MP3 Tag Reader is a C-based application designed to read, display, and edit metadata stored in MP3 audio files. It uses ID3 tags,  to extract information such as song title, artist, album, year, and genre.

The application supports reading and displaying existing song details, editing tag information, and saving the updated metadata back to the MP3 file.

✨ Features

- Read Tags: Extracts metadata from MP3 files.
- Display Tags: Displays song details such as title, artist, album, and year.
- Edit Tags: Modifies existing metadata fields.
- Save Changes: Updates the modified tag information in the MP3 file.
- Tag Validation: Checks whether the MP3 file contains valid ID3 tags.
- Command-Line Interface: Accepts filenames and operations through command-line arguments.

Technologies Used

- Language: C
- Concepts: Pointers, Structures, Command-Line Arguments, and Modular Programming.
- Compiler: GCC
